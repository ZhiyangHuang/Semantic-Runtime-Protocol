# SRP v1.1 Release Note

## Version Status

Release date: `2026-07-19`

`v1.1` freezes the reproducible governance evidence layer of Semantic Runtime Protocol.

This release establishes the artifact, evaluation, and provenance contracts required to evaluate semantic transition governance under frozen runtime conditions.

## Frozen Components

- Semantic transition evidence contract
- Boundary evidence generation workflow
- External evaluation registry schema
- Adapter resolution contract
- `transition_role` semantics
- LongMemEval external reality check protocol
- Artifact provenance and integrity records

## Evidence Boundary

The release validates that:

- semantic transition variables can be represented under an explicit runtime contract
- governance diagnostics can coexist with external benchmark scoring
- evidence generation can be reproduced from frozen artifacts
- evidence quality remains separate from execution authority

## External Validation

The LongMemEval reality check is included as:

- external workload validation
- scorer alignment evidence
- runtime reproducibility evidence

It is not:

- a benchmark ranking claim
- a memory architecture comparison
- evidence of universal performance superiority

## Non-Goals

This release does not introduce:

- new memory architectures
- retrieval optimization methods
- autonomous semantic mutation
- learned authority mechanisms
- benchmark leaderboard objectives

## Future Boundary

Future extensions belong to `v1.2` and later milestones, including:

- boundary generation research
- provenance graph extensions
- cross-domain governance consistency
