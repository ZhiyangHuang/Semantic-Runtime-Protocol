# Archive Index

This directory stores preserved but non-primary outputs.

It exists to reduce clutter in the main `results/` layer without deleting information that may still matter for later audit, debugging, or appendix-level reference.

## Buckets

- `smoke/` - protocol and qualification smoke runs
- `comparison/` - exploratory comparison tables and related outputs
- `latency/` - latency-oriented exploratory outputs
- `debug/` - preserved debugging outputs
- `generated/` - generated config artifacts associated with archived runs
- `duplicate_namespace/` - snapshot of accidental duplicate output roots from earlier path bugs

## Rule

Files in this archive are preserved, but they should not be treated as the default paper-facing evidence unless explicitly promoted back into a canonical namespace.
