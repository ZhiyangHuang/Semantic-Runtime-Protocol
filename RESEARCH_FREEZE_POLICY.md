# Research Freeze Policy

This document freezes the current SRP research boundary.
It is a project-level policy, not an experiment result and not a mechanism design.

## Frozen Core Architecture

- Observe
- Validate
- Optimize
- Verify
- Recover
- Recommend
- Govern
- Execute

## Frozen Core Claims

- SRP is a governance framework for semantic runtime evolution.
- SRP evaluates governed semantic recovery rather than claiming universal long-term memory.
- Representation changes are evaluated; universal invariance is not assumed.

## Current Development Priority

- External validity
- Strong baselines
- Statistical rigor
- Reproducibility

## Changes Requiring Strong Justification

The core theory should only be revised if:

- repeated experiments consistently contradict the theory's predictions
- a strong community baseline exposes a systematic failure mode
- multiple independent experiments cannot be explained by the current framework

## Working Rule

Freeze theory first.
Increase evidence next.
Revise theory only when evidence forces it.
