# SRP Research Questions

This document freezes the top-level research questions for SRP.

---

## RQ1

Can structured semantic state preserve task-relevant information?

## RQ2

Where does semantic degradation occur during the SRP lifecycle?

## RQ3

How should structured semantic state be reconstructed into a compact executable state?

## RQ4

Can repair compensate for reconstruction errors?

---

## Stability Policy

- These questions are the highest-level organizing principles for SRP.
- Experiments, metrics, and code should be interpreted through these questions.
- Changes should be made only when a new research direction is explicitly adopted.
