# Cleanup Review

This folder isolates cleanup-process files so they can be reviewed and removed later without touching the canonical experiment or paper structure.

## Purpose

These files are not part of the long-term paper package.

They exist to:

- document cleanup intent
- prevent over-deletion
- preserve a reversible review lane
- separate short-lived cleanup notes from permanent governance notes

This folder is a short-lived review namespace.
It should not be confused with the long-lived governance layer in:

- `docs/strategy/`

## Files

- `temporary1.md` - experiment/governance cleanup guardrail
- `temporary2.md` - data/results cleanup guardrail
- `temporary3.md` - final cleanup pass guardrail
- `CLEANUP_REVIEW_MANIFEST.md` - what was moved, added, and deleted in the review pass

## Removal Rule

If the repository structure is accepted after review, this folder can be deleted as one unit.
