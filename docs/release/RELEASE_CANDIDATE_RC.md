Included:

- SRP evidence surface v1.1
- Cross-environment analysis
- External validation for LongMemEval and ARC
- Capability-stress evidence for MMLU and HumanEval
- Claim alignment across abstract, discussion, results, and limitations
- Caption and table schema consistency audit

Excluded:

- New experiments

- STFB schema changes
- Additional metrics
- Changes to the frozen SRP v1.0 or STFB v0.1 boundaries

Future work proceeds under:

- SRP v1.1
