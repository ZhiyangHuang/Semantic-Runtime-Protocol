# SRP v1.0.0 - Semantic Runtime Protocol arXiv Release Candidate

## Status

This release freezes the arXiv submission state of Semantic Runtime Protocol (SRP).

The release represents the finalized technical report artifact with aligned paper claims, reproducible evidence boundaries, and synchronized submission metadata.

## Frozen Components

The following components are frozen:

- Research claims
- Terminology and positioning
- Evidence surface
- Evaluation interpretation
- Artifact classification
- arXiv metadata
- README positioning

## Release Alignment

The release maintains a consistent positioning across:

- Paper manuscript
- Root README
- Paper documentation
- Submission metadata
- Generated PDF artifact

SRP is presented as:

> A semantic runtime governance framework that controls the admissibility of semantic state transitions through explicit validation, evidence, and authorization boundaries.

The release does not position SRP as:

- a memory optimization system
- a retrieval acceleration method
- a benchmark improvement technique
- a universal semantic correctness mechanism

## Evidence Boundary

This release preserves the distinction between:

- evidence and authority
- recommendation and execution
- validation and mutation

Evaluations are reported under frozen runtime contracts and evaluated settings.
